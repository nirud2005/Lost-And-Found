# 🎒 Smart Lost & Found – ของหายได้คืน มศว

เว็บแอปประกาศของหาย/เก็บของได้ สำหรับนิสิตมหาวิทยาลัยศรีนครินทรวิโรฒ
ไฟล์เดียว ไม่ต้องติดตั้งอะไร เปิด `index.html` ก็ใช้งานได้ทันที

## ฟีเจอร์
- 🔍 ค้นหาและกรองรายการ (ทั้งหมด / ของหาย / เก็บได้)
- ➕ โพสต์ประกาศพร้อมแนบรูป (ย่อรูปอัตโนมัติ)
- ✨ จับคู่รายการที่อาจตรงกันให้อัตโนมัติ
- 📍 แนะนำจุดนัดรับที่ปลอดภัย
- 🌗 รองรับโหมดมืด/สว่าง และใช้งานบนมือถือ

## วิธีใช้งาน
```bash
git clone https://github.com/<your-username>/swu-lost-found.git
cd swu-lost-found
# เปิด index.html ในเบราว์เซอร์ได้เลย
```

## เผยแพร่ด้วย GitHub Pages
1. Push โค้ดขึ้น branch `main`
2. ไปที่ **Settings → Pages → Source** เลือก **GitHub Actions**
3. รอ workflow ทำงาน แล้วเว็บจะอยู่ที่ `https://<your-username>.github.io/swu-lost-found/`

## ข้อจำกัดปัจจุบัน
ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ จึงเห็นเฉพาะในเครื่องตัวเอง
